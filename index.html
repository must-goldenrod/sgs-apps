sgs channel tools

sgs is a private tool that one owner uses to manage their own YouTube channels: Bytecut, hwie, Since_Glitched and what if guitar.

With the owner's Google sign-in it does three things through the YouTube API Services:

  • uploads and schedules videos that the owner has approved, to the owner's own channels;
  • reads the owner's own channel and video statistics (views, likes, comments, watch time, subscribers) to see which videos work;
  • shows those numbers on a dashboard that only the owner can open, on the owner's own computer.

It is not offered to the public, and it never reads or changes anyone else's channel.
